# 🌌 Django-проект Torch (Backend API)

**Torch** — это комплексная backend-платформа для LMS-системы онлайн-обучения (Learning Management System). Проект предоставляет гибкий REST API, построенный на базе Django REST Framework, со строгим разделением зон ответственности и архитектурным паттерном **Service Layer** для интеграции со сторонними платежными шлюзами.

---

## 🏗 Архитектура и структура модулей

Проект разделен на два ключевых доменных приложения:

### 1. `users`
* Отвечает за аутентификацию, регистрацию и разграничение прав доступа.
* Использует кастомную модель пользователя `CustomUser`.
* Реализует безопасность сессий с помощью JWT-токенов.

### 2. `aurora`
* **Контент:** Управление каталогом онлайн-обучения — курсы (`Course`) и отдельные уроки (`Lesson`), связанные отношением One-to-Many.
* **Финансы:** Учет транзакций через модель `Payments` (поддерживает наличные, переводы на счет и интернет-эквайринг).
* **Интеграция со Stripe:** Модуль автоматической генерации платежных ссылок через инструмент Stripe Checkout и асинхронный прием уведомлений (Webhooks). Вся логика API Stripe вынесена из контроллеров в изолированный сервисный слой `StripePaymentService` (`services.py`).

---

## 🛠 Технологический стек

* **Язык программирования:** Python 3.x
* **Веб-фреймворк:** Django + Django REST Framework (DRF)
* **Платежный шлюз:** Stripe API (Интеграция через современный SDK `StripeClient`)
* **База данных:** PostgreSQL / СУБД проекта

---


### Как протестировать платежи (Stripe)
1. Установите [Stripe CLI](https://github.com).
2. Выполните команду `stripe login` для авторизации.
3. Запустите вебхуки: `stripe listen --forward-to localhost:8000/api/v1/payments/webhook/`
4. Скопируйте полученный `whsec_...` в ваш файл `.env` в переменную `STRIPE_WEBHOOK_SECRET`.
5. Запустите Django-сервер и сделайте тестовый платеж.

* **Брокер сообщений & Кэш:** Redis (Разворачивается локально через Docker-контейнер)
* **Асинхронные задачи:** Celery (Используется для фоновой обработки вебхуков Stripe, отправки email и тяжелых вычислений)

## 🚀 Быстрый старт (Локальная разработка)

В проекте настроена автоматизация, которая одной командой поднимает всю необходимую инфраструктуру.

### Предварительные требования
1. Установлен и запущен **Docker Desktop** (необходим для автоматического поднятия Redis).
2. Активировано виртуальное окружение вашего проекта (Poetry / venv).

### Запуск проекта
Вместо стандартного `runserver` используйте кастомную команду автоматизации:
```bash
python manage.py dev
```

**Что делает эта команда автоматически:**
1. Проверяет наличие Docker в системе.
2. Скачивает образ и запускает изолированный контейнер `torch-redis` на порту `6379`.
3. Запускает локальный веб-сервер Django на `http://127.0.0`.
4. Включает воркер Celery в режиме совместимости с Windows (`-P threads`).

При нажатии `Ctrl + C` в терминале скрипт корректно завершит процессы Django и Celery, а также остановит контейнер Redis, освобождая оперативную память вашего ПК.
